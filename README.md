# ASM FAMILY SHIELD — PWA iPhone

## Publication GitHub Pages
1. Créez un dépôt GitHub.
2. Envoyez le contenu de ce dossier à la racine du dépôt.
3. Settings > Pages > Deploy from a branch > main / root.
4. Ouvrez l'URL HTTPS GitHub Pages dans Safari sur iPhone.
5. Partager > Sur l'écran d'accueil > Ajouter.

## Fonctions
- Horloge flip
- Membres de famille stockés localement
- GPS avec consentement explicite
- Liens WhatsApp et appels
- SOS avec lien de position
- Enregistrement de messages vocaux
- Installation PWA et cache hors ligne

## Limites techniques importantes
Un numéro de téléphone ne permet pas de localiser quelqu'un. Chaque personne doit consentir au partage GPS.
GitHub Pages est un hébergement statique : la synchronisation temps réel de plusieurs membres nécessite un backend (par ex. Firebase/Supabase) avec authentification et règles d'accès.

## Publication GitHub Pages — package final
1. Créez un dépôt GitHub public ou compatible Pages.
2. Envoyez tous les fichiers de ce ZIP à la racine du dépôt (pas le dossier parent).
3. GitHub > Settings > Pages > Build and deployment > Deploy from a branch.
4. Choisissez `main` et `/(root)`, puis Save.
5. Ouvrez l’adresse HTTPS fournie par GitHub Pages dans Safari sur iPhone.
6. Safari > Partager > Sur l’écran d’accueil > Ajouter.

L’icône SOS ASM FAMILY SHIELD est intégrée en 180, 192, 512 et 1024 px.
